# Grid-Research-Microgrid-DER

A Python-based research project for analyzing and simulating microgrids with Distributed Energy Resources (DER).

## Overview

This repository contains research code and tools for studying microgrid behavior, optimization, and control strategies with distributed energy resources. It provides simulation, analysis, and modeling capabilities for grid research applications.

## Features

- **Microgrid Simulation**: Comprehensive simulation framework for microgrid operations
- **DER Modeling**: Support for distributed energy resource modeling and analysis
- **Grid Analysis**: Tools for power flow analysis and grid stability assessment
- **Data Processing**: Utilities for handling and processing grid operational data

## Requirements

- Python 3.7+
- Dependencies listed in `requirements.txt`
